Implementation Concerns (Stuff you can fix later):
1. Blocking all IPC except Aegis is tricky

You may need a kernel primitive or a sandbox policy enforced by Singularity.

2. “block_unix_sockets: true”

Core daemons rely on their sockets—make an allowlist system.

3. Mandatory executable verification

You will need:

signed packages

signed binaries

origin metadata

a package manager that stores install timestamps

Totally doable, just extra work.

4. Screen recording & keystroke logging

These need:

a privileged “monitoring daemon”

kernel hooks or a compositor hook

Still doable.

5. “Disable privilege escalation entirely”

You’ll need to override all methods:

setuid bits

capabilities

polkit

ptrace

/proc writes

kernel syscalls

This is actually perfect for a microkernel because your kernel has fewer syscalls.
